# Meeting reminder policy

Use the meeting title and meeting code from the current Calendar event on the second phone.

From the attendee workbook, select rows whose `meeting_code` matches the current Calendar event and whose status is not archived.

Match the selected attendee names to Contacts on the first phone.

Send each selected attendee one concise, positive confirmation containing the current meeting title and meeting code.

Do not send a reminder for archived attendee rows.
