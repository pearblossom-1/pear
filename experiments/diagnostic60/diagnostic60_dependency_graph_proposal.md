## Edge semantics

- `inject_frozen_gold_semantic_handoff`: inject the source-grounded gold information contract, never the predecessor run output.
- `semantic_postcondition`: inject only the downstream-needed facts from a predecessor's reviewed gold environment postcondition.
- `artifact_transfer`: materialize the exact gold artifact at the downstream location; a prose summary is insufficient.
- Same-layer stages on different devices remain separate. Same-layer independent outputs have no edge even when the original instruction lists them sequentially.
- Every retained same-device later-layer re-entry has at least one dependency on another stage; otherwise generation fails rather than freezing an over-split graph.

The structural family value carried from sampling is used only as a near-duplicate/dedup signature. It is not a formal task-family taxonomy and did not affect this graph review.
