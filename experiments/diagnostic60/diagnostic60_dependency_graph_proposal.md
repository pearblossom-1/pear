## Edge semantics

- An information edge means the downstream stage receives a reviewed gold semantic handoff, never the actual predecessor output.
- An environment-state edge means the downstream initialization materializes the predecessor's gold postcondition from the oracle/evaluator contract.
- Stages in the same layer are independent proposals. Different devices in the same layer remain separate stages.
- The same device appearing in multiple layers is intentional and must remain split unless human review changes the dependency graph.
