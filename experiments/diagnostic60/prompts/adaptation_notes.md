# Diagnostic-60 Isolated Prompt Adaptation Notes

The runtime Core-200 GPT-5.5 system prompt constructor in
`mdcbench/runner/run_llm_task.py::_system_message` is the sole mother. The
saved mother snapshot uses placeholders only for the runtime device list and
action spaces; the three isolated templates are generated by
`derive_isolated_system_prompt_template` from that constructor.

The adaptation is intentionally device-local:

- preserve general agent behavior, recovery, completion, artifact fidelity,
  observed-value fidelity, and the response envelope;
- replace multi-device observation/topology/routing text with one frozen
  device identity and one current observation;
- retain only the corresponding Android, Linux, or SmartHome action reference;
- omit model-supplied top-level `device_id`; the runner supplies the frozen
  instance from the executable spec;
- use one prompt per device type, with no information/environment-stage split;
- add no task-specific strategy, app hint, or evaluator hint.

The three unified diff files compare each generated isolated template with the
same baseline constructor instantiated for that device type and placeholders.
